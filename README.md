## 报告只声称三件事

1. **模拟输出**：在人为设定的三档先验与代理判据（滚动 3 月记忆内 ≥2 区域处于 state 2）下，五年累计**代理触发比例**为 0.0003% / 0.0145% / 1.4432%（每档 10⁶ 条路径，命中 3／145／14,432）。这是"代理事件的模拟概率"，**不是**"真实 WW3 的五年发生概率"。
2. **可识别性**：该代理判据未经历史验证；真实事件的五年概率在当前数据下**不可识别**，本模型不去冒充它。
3. **决策含义**：最重要的结果不是中间那个数，而是先验敏感性 **4811×**——它比任何已讨论的协变量扰动都大三个数量级以上。

## 口径边界（引用本仓库时必须保持）

- 中间档 0.0145% 不是"最合理预测"。
- 17.07% 零正例上界的对象是 **pair-year 严格终端五年累计率**，与上面的系统级代理概率**不是同一个估计对象，不得相除**（早先的 1178× 论证已撤回）。卡 6 的 40.2× 仍然有效，因为那三条上界同一估计对象、只是分母 N 不同（N=80 可核验暴露 vs N=3,518 折叠分母）。
- `P ∝ H^2.46` 只是本次 5 个已模拟期限上的经验斜率，不是结构定律。
- ρ 与终端阈值受冻结决策④约束（`ww3_terminal_layer_gate_freeze_v1.md`，不在本仓库）；任何涉及 ρ 的新机制在正式修订冻结前只能作为 L3 先验情景，不进估计流程。
- **卡 8（美债）**：文献（Krainin, Ramsay, Wang & Ruggiero 2022, CMPS 39(5)）只支持"权力转移 × 债市基本面"的**交互机制**，且原文含两个符号相反的主效应，不支持把利息支出写成单调 `p12` 乘数；">90% 的预算"是以**收入**为分母（÷支出 = 65.7%）；2026 年 3 月那个收益率窗口对所声称的"避险属性翻转"**不可识别**——不可识别 ≠ 不存在关系。卡 8 标着"先验假设，未估计"，刻意不写进页首摘要。
